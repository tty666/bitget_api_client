# Security Policy

## Supported Versions

We provide security updates only for the latest stable release of this project.  
Please make sure you are running the most recent version before reporting vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ Supported        |
| older   | ❌ Not supported    |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.  
Instead, report it responsibly by contacting us at:

**[theentity666@gmail.com]**

We will review and respond to your report within **5 business days**.

---

## Responsible Disclosure Guidelines

- Provide a clear and detailed description of the vulnerability.  
- Include steps to reproduce the issue if possible.  
- Do not share the vulnerability publicly until it has been acknowledged and fixed.  
- Once the issue is resolved, we will acknowledge your contribution (if you wish).  

---

## Security Best Practices

If you use this library in production, we recommend:  
- Keeping dependencies up to date.  
- Rotating API keys regularly.  
- Using the least-privilege principle for API credentials.  
- Monitoring account activity for suspicious behavior.
